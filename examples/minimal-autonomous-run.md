# Minimal Autonomous Run

Use this prompt from the root of a repository where the skill is installed:

```text
[$manage-autonomous-repo](C:\Users\<you>\.codex\skills\manage-autonomous-repo\SKILL.md)
Use subagents as per skill instructions.

Establish the repo baseline, create or update the agent-readable docs, identify independent tracks, and start the first safe parallel batch.
```

Expected first outputs:

- Git and documentation baseline.
- `docs/ai/state.md` or equivalent.
- Track portfolio.
- Task cards for selected subagents.
- Source-control plan.
